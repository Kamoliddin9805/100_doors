# 100 Doors: Bug Town

Mobile-first puzzle adventure prototype.

## Playable now
- Doors 1–10 are interactive
- Doors 11–100 are shown on the map as locked chapters
- Local progress and coins are saved in localStorage
- Touch D-pad + keyboard controls
- Uses the supplied Mimi character artwork

Static site: open `index.html` or deploy the repository to Vercel.
